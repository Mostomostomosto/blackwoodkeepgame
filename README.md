# Blackwood Keep — sitio web

Sitio estático oficial de Blackwood Keep. La página se sirve desde la raíz del repositorio para GitHub Pages.

## Estructura

- `index.html`: contenido y estructura de la página.
- `css/styles.css`: estilos visuales y responsive.
- `js/main.js`: navegación, selector de idioma, galería y reproductor.
- `assets/`: imágenes y recursos que usa la web.
- `docs/`: especificaciones, enlaces de vídeo y referencias visuales del proyecto.

## Publicación

En GitHub, configura Pages para publicar desde la rama principal y la carpeta raíz (`/`).
## Juego web

La build HTML5 del capítulo está en game/ y se abre desde los botones de juego. Sus rutas son relativas para que funcione tanto en GitHub Pages como bajo la ruta del proyecto.
